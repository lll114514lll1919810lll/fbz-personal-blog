## 为什么建立这个博客

平时遇到技术问题，我总是习惯上网搜索寻求答案，但是，搜索引擎推荐项早已被 AI 生成的 **低质量** 文案占领：所谓的“万能解决方案”都是车轱辘话来回说，实用价值趋于0。所以，建立这个博客，不是拒绝 AI 生成内容，也不指望被全世界看见，而是为了让摸索出来的，真正有价值的内容和观点能留存下来。

## 为什么选 Next.js

博客本质上是一个**以内容为中心的网站**，需求可以拆成三块：

1. 把 Markdown 渲染成网页
2. 列表页和详情页
3. 搜索引擎能看懂

Next.js 的 App Router 把这三件事都做完了，而且：

- **构建时预渲染成静态 HTML**，访问时几乎不需要等待
- **每篇文章有独立的 `<head>`**，分享到微信、Twitter 时有漂亮的卡片
- **暗色模式跟随系统**，不需要用户手动切换

## 关于 MDX

MDX 就是「能在 Markdown 里写 JSX」。普通 Markdown 只能写文字和图片，MDX 可以直接引入 React 组件——以后需要图表、代码演示、互动组件的时候会很有用。

比如这段引用：

> 工具会塑造使用者，使用者也会反过来塑造工具。
