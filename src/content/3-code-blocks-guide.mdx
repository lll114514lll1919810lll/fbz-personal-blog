## 语法高亮

代码块用 Shiki 在构建期高亮，语法树来自 TextMate 语法定义，和 VS Code 同一套引擎。
支持 ts、tsx、js、jsx、json、bash、css、html、md、mdx、python、rust 等常用语言。

注意：**语言标记得自己写，Shiki 不会猜。** 不写就按纯文本处理，一点颜色都没有，
详见下面的「不写语言会怎样」。

## 明暗双主题

同一段代码会同时输出两套颜色：

- 浅色系统用 github-light
- 深色系统用 github-dark

切换配色纯靠CSS，不加载任何 JavaScript，也不会闪烁。

## 复制按钮

右上角常驻一个「复制」按钮，点击后变成「已复制」，两秒后自动恢复。
它默认只有一层浅灰色，鼠标移上去才浮出底色和边框，不会跟代码抢注意力。

注意：浏览器的剪贴板 API 只在 HTTPS 或 localhost 下可用。
用局域网 IP 以 http 访问时复制会静默失败，这时仍可以手动选中复制。

## 语言标签

左上角显示语言名，纯装饰，不占额外空间。

## 折叠长代码

超过 420px 的代码块，工具条上会多出一个「折叠」按钮。点一下只露出开头九行左右，
底部有渐变提示下面还有内容，再点一次展开。收起和展开之间有 0.3 秒的高度过渡，
箭头也跟着翻方向。默认就是展开的，长代码不用管它。

和「复制」一样，这个按钮也是常驻的，只是浅灰一层，不点它不会注意到。

短代码块不给这个按钮。十来行的代码折起来没意义，多一个按钮只会让工具条变吵。

下面这段可以点着试试，它其实是本仓库 CI 里那几条产物断言的本地版：

```bash
# 把静态导出产物过一遍，确认没有会在托管端 404 的引用
set -euo pipefail

OUT=out
PORT=8788

# 导出构建不生成 _next/image 路由，产物里一旦出现就是线上 404
if grep -rq "_next/image" "$OUT" --include="*.html"; then
  echo "产物里有 /_next/image 引用" >&2
  exit 1
fi

# 每个 <table> 都要有配对的 table-scroll，否则窄屏会整页横向溢出
tables=$(grep -ro '<table' "$OUT" --include="*.html" | wc -l)
wrapped=$(grep -ro '<div class="table-scroll">' "$OUT" --include="*.html" | wc -l)
if [ "$tables" -ne "$wrapped" ]; then
  echo "有 $((tables - wrapped)) 个表格没包 table-scroll" >&2
  exit 1
fi

# sitemap 里没有 <loc> 说明 siteConfig.url 没配
grep -q "<loc>" "$OUT/sitemap.xml" || { echo "sitemap 是空的" >&2; exit 1; }

echo "产物检查通过，表格 $tables 个"
python3 -m http.server "$PORT" --bind 127.0.0.1 --directory "$OUT"
```

门槛按渲染高度算，不看行数，所以窄屏上代码折行多，行数少一点也会出现按钮。

## 横向滚动提示

代码超出宽度时可以横向滚动，右侧会出现一层渐变提示还有内容。
滚到最右边时这层会撤掉，不会一直压着最后几个字符。
实测一段很长的配置：

```ts
export const config = {
  server: { port: 3000, host: "0.0.0.0" },
  experimental: { optimizePackageImports: ["lucide-react", "date-fns", "@/lib/utils"] },
  images: { formats: ["image/avif", "image/webp"], minimumCacheTTL: 14400 },
  async redirects() { return [{ source: "/old-blog", destination: "/blog", permanent: true }] },
} satisfies Record<string, unknown>
```

## 不写语言会怎样

没有语言标记时，Shiki 会当作纯文本处理，不着色：

```
这是一段纯文本代码块
不会被着色
但依然有复制按钮和边框
```
